NoteBest ESM-2 variant; still below V2
Root cause: Frozen ESM-2 encodes evolutionary fitness, not RNA-binding specificity. ESM-2 was pretrained to predict masked amino acids using evolutionary covariance — this captures secondary structure and conservation, not whether a residue participates in RNA contact. With only 169 training RBPs, fine-tuning 650M parameters would overfit severely. Conclusion: ESM-2 is not helpful until we have ≥1000 training RBPs.

RNAcompete ucRBP Hughes Lab, unconventional RBPs 667 (568 in file) 7.6M 4 35–41 nt Same dual-filter — but relative threshold inflates noise Low Do NOT use without Z-filter
ucRBP reliability problem: ucRBP tests unconventional (non-canonical) RBPs. Only ~23 of 667 show reproducible RNA-binding signal (max k-mer Z ≥ 5.0). The dual-filter uses relative 90th-percentile thresholds — a protein with no RNA specificity still gets "positives" if its intensity distribution is broad enough. This creates ~2.4M spurious positive labels. Must filter by max(z_setAB) ≥ 5.0 before any use in training or benchmarking.
