Shared input encoding & training recipe (all CNN models)

Sequence → tensor

RNA: string → uppercase, pad/truncate to L=60 one-hot (60 × 4) channels A,U,G,C Prot: string → uppercase, pad/truncate to L=700 one-hot (700 × 20) standard 20 AA # SeqDataset — src/data/dataset.py

Training hyperparameters (V2/V4 default)

LossBCEWithLogitsLoss(pos_weight = n_neg/n_pos)
OptimizerAdam lr=5e-4
SchedulerCosineAnnealing T_max=epochs, eta_min=lr×0.01
Regularizationdropout=0.3, grad clip max_norm=1.0
Early stoppatience=8 on val AUPRC
Samplernone (no WeightedRandomSampler)
Outputlogit → sigmoid → P(bind)

ConvBranch — building block used in V2, V3*, V4

src/models/cnn_model.py
Input (B, L, C) → transpose (B, C, L) → Conv1d + BatchNorm + GELU + Dropout (repeated 3×) → global max-pool over length → vector (B, out_dim) Default filters: [128, 256, 256] RNA kernels: [7, 5, 3] Prot kernels: [11, 7, 5] # wider kernels for longer AA motifs

Layer 1 Conv1d with kernel k ≈ learned PWM of width k. Max-pool = "does this motif appear anywhere in the sequence?"

V3 — RNA CNN + frozen ESM-2 mean-pool

worse than V2 ESM2RNACNNModel · scripts/08_train_generalized_v3.py
RNA one-hot (B, 60, 4) → ConvBranch → (B, 256) Prot ESM-2 mean embedding (B, 1280) # precomputed, frozen → Linear 1280→256 + LayerNorm + GELU + Dropout → (B, 256) concat (B, 512) → MLP 512→256→64→1

Protein branch has no sequence-level conv — one vector per protein. Test AUROC 0.634. Mean-pool dilutes binding-domain signal.

V3b — RNA CNN + Protein CNN + ESM-2 side channel

worse than V2 V3bModel · scripts/09_train_generalized_v3b.py
RNA one-hot (B, 60, 4) → ConvBranch → (B, 256) Prot one-hot (B, 300, 20) → ConvBranch → (B, 256) ESM-2 mean (B, 1280) → Linear 1280→128 + LN + GELU → (B, 128) concat (B, 640) → MLP 640→256→64→1

Three parallel protein/RNA signals concatenated. Test AUROC 0.666. ESM-2 helps motif-poor proteins but hurts motif-rich ones on net.

V3c — RNA CNN + ESM-2 per-residue CNN

≈ V2, not better V3cModel · scripts/10_train_generalized_v3c.py
RNA one-hot (B, 60, 4) → ConvBranch [128,256,256] kernels [7,5,3] → (B, 256) Prot ESM-2 per residue (B, 300, 1280) # frozen, precomputed → Linear per position 1280→64 + LN + GELU → Conv1d [128, 256] kernels [7, 5] + max-pool → (B, 256) concat (B, 512) → MLP 512→256→64→1

Adds positional conv on top of ESM-2 residues (not raw AA). Test AUROC 0.685. Closest ESM-2 variant to V2 but still below.

V4 — Dual-branch CNN + bilinear interaction

next experiment RNABindingV4 · src/models/interaction_model.py · scripts/21

Same ConvBranch encoders as V2. Difference is how RNA and protein embeddings are combined before the MLP head.

# BilinearInteraction (hadamard low-rank pooling) rna_emb (B, 256), prot_emb (B, 256) inter = LayerNorm( Linear_a(rna) ⊙ Linear_b(prot) ) → (B, 256) # ⊙ = element-wise product; captures multiplicative RNA×protein feature combos
Mode (--interaction)MLP input dimWhat gets concatenated
concat 512 rna_emb + prot_emb (= V2, backward compatible)
bilinear 256 inter only
concat_bi ★ default 768 rna_emb + prot_emb + inter
# concat_bi full forward pass rna_emb, prot_emb (256 each) from ConvBranches inter = BilinearInteraction(rna_emb, prot_emb) (256) [optional] src_emb = Embedding(dataset_source) (16) # --use_source_emb concat (768 + 16) → MLP 768→512→128→32→1 # head_dims default in V4

Source embedding maps assay tag (selex_rbns / rnacompete / eclip) to 16-d vector — lets model calibrate per-assay bias, not used in first V4 run unless flagged.

Model architectures — planned (not yet implemented)

Phase 3C — Multi-task V2/V4 + affinity head

planned
Shared trunk: V2 or V4 encoder → hidden vector h (B, 64) # before final linear head_cls: Linear 64→1 → binding logit head_affinity: Linear 64→1 → log-intensity prediction Loss = BCE(cls) + λ · MSE(affinity) # affinity loss masked where label missing Targets: RNAcompete rows: probe_intensity (log-scaled) RBNS rows: R_max (log-scaled) SELEX rows: cls only

Prototype exists for MLP only: RNABindingMLPWithAffinity in mlp_model.py. CNN version will split the V2/V4 head into two outputs.

Phase 4 — Localization auxiliary heads

planned
# RNA motif position — auxiliary on ConvBranch feature maps rna_feat (B, 256, 60) # before max-pool, from last conv layer → Conv1d 256→1 kernel 1 → position scores (B, 60) → softmax → predicted motif start distribution Weak label: start index of top enriched 7-mer (from SELEX/RNAcompete analysis) # Protein domain attribution — auxiliary on prot feature maps prot_feat (B, 256, 700) → Conv1d 256→1 → per-residue importance (B, 700) Weak label: UniProt RRM/KH/Pumilio domain boundaries

Main binding classifier unchanged. Aux losses added with small weight. Does not require new labels beyond existing motif/domain annotations.

Phase 5 — Variant effect (inference-only, no new architecture)

planned
Given trained model f(prot, rna): wild-type: score_wt = σ( f(prot_wt, rna) ) mutant: score_mut = σ( f(prot_mut, rna) ) # one AA changed in one-hot input Δscore = score_mut − score_wt Uses Phase 3C affinity head if available (Δ on log-intensity scale), otherwise Δ on probability scale.

Phase 7 — Structure channels (input extension)

planned
RNA input: one-hot (60×4) + structure features (60×F) # F = pairing prob, accessibility from ViennaRNA — appended per position → ConvBranch in_channels = 4 + F Prot input: one-hot (700×20) + domain mask (700×1) # optional: ESMFold-derived features per residue
